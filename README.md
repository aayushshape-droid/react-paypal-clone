# PayPal Open - React Project

A simple single page React app made for a college assignment. All data is static.

## How to run

```
npm install
npm run dev
```

Then open the link shown in the terminal (usually http://localhost:5173).

## Features

- Navigation bar with links that scroll to sections on the same page
- Personal / Business toggle in the hero section
- Log In, Sign Up and Contact Sales buttons scroll to simple static forms on the same page
- Plain HTML, CSS, React and basic JavaScript only
